# Cервис бронирования отелей
Мое первое веб-приложение реализованное на **Django**!

## Запуск приложения
Для запуска нашего сервиса необходимо использовать веб-сервер **gunicorn**. Перейдите в папку `app/src/` с помощью команды `cd`:
```
cd src
```
Команда для запуска выглядит так:
```
gunicorn --workers 1 --bind 0.0.0.0:8000 bookingsite.wsgi:application
```
Ее необходимо запускать в командной строке, *обязательно* находясь в директории `app/src/`.

После этого можно открыть браузер и ввести  `127.0.0.1:8000/docs`, чтобы протестировать **API**

### Dockefile

Для запуска сервиса с помощью **Docker** необходимо создать образ находясь в корне проекта с помощью команды:
```
docker build -t hotel-booking-service:v1 .
```
После этого можно запустить наш образ:
```
docker run --rm -p 8000:8000 --env-file .env hotel-booking-service:v1
```

#### docker-compose
Для запуска приложения в корне проекта в терминале введите команду:
```
docker-compose up --build
```
Чтобы остановить:
```
docker-compose down
```
